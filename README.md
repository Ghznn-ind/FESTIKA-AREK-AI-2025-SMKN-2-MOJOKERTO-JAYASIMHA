## 📖 About The Project

**Ngulik Si Jatim** is a Python-based application developed to participate in the **FESTIKA AREK AI 2025** competition, representing **SMKN 2 Mojokerto** in the Python Application category.

The project was designed to deliver an interactive and innovative digital solution that explores the potential, culture, and wealth of information surrounding **East Java (Jawa Timur)** through the use of Python programming technology.

---

## ✨ Key Features

* **Interactive Interface:** A clean, intuitive, and user-friendly interface built with Python.
* **Smart Data Processing:** Efficient data processing to deliver relevant information quickly and effectively.
* **East Java Exploration:** Provides informative features focused on the potential, culture, and regional information of East Java.
* **Modular Code Structure:** Developed using clean, organized, and maintainable coding practices.

## 🚀 Getting Started

Follow the steps below to run the project locally on your computer.

### Prerequisites

Make sure Python is installed on your system:

```bash
python --version
```

### Installation

#### 1. Clone the Repository

Clone this repository to your local machine:

```bash
git clone https://github.com/Ghznn-ind/FESTIKA-AREK-AI-2025-SMKN-2-MOJOKERTO-JAYASIMHA.git
```

#### 2. Navigate to the Project Directory

```bash
cd FESTIKA-AREK-AI-2025-SMKN-2-MOJOKERTO-JAYASIMHA
```

#### 3. Install Dependencies

If the project includes a `requirements.txt` file, install the required dependencies:

```bash
pip install -r requirements.txt
```

### Running the Application

Run the main Python application:

```bash
python main.py
```

> **Note:** If the project's main entry point uses a different filename, replace `main.py` with the appropriate file, such as `app.py`, `gui.py`, or another entry point.
